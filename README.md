Personal Budget Tracker

A Python-based personal budgeting application that helps users track monthly income and expenses, calculate remaining money, and monitor their savings percentage.
This project was built as part of my journey toward becoming a software developer and demonstrates my understanding of Python fundamentals, functions, loops, lists, user input, validation, and basic financial calculations.

Features

* Enter and track monthly income
* Add custom expense categories
* Enter standard monthly expenses such as:
    * Rent
    * Transportation
    * Food
    * Entertainment
* Calculate total monthly expenses
* Calculate remaining income
* Calculate savings percentage
* Display a monthly budget summary
* Validate numeric input
* Prevent negative expense amounts
* Allow users to continue adding expenses until they enter done

Technologies Used

* Python 3
* Git
* GitHub

How It Works

The application begins by asking the user to enter their monthly income. The user can then enter custom expenses and their corresponding amounts.
After the custom expenses are entered, the application collects additional standard expenses and calculates the user’s overall monthly spending.
The program then displays a summary containing:

* Monthly income
* Total expenses
* Money remaining
* Savings percentage
* Whether the user saved money or overspent
